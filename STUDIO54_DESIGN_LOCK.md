# Studio 54 — layered intro design

This contract replaces the original single-PNG desktop menu following the user's October 10, 2026 redesign brief. The previous screenshot-only layout is intentionally superseded.

## Scene and assets

- `src/template.html` is the editable source; `deploy/index.html` is generated by `npm run build`.
- The intro uses a shared, uncropped 16:9 stage. Desktop target sizes: 1920×1080 and 1440×900. Wider/taller screens retain the whole composition with letterboxing. Existing game zoom remains enabled outside the intro.
- `deploy/uploads/intro-artwork.png` contains the comic club facade, neon signs, bouncer, white branded party car, anatomically corrected woman and wet pavement. It contains no menu buttons, rules, speech balloons, leaderboard or event posters.
- `intro-landchi.jpeg` and `intro-mazer.jpeg` are byte-for-byte copies of the originals supplied by the user. They are separate image elements in equally sized frames, without blur or cropping.
- All menu controls, ticker, statistics, leaderboard and speech balloons are independent HTML components. START sits below the car, with an empty strip before the bottom HUD.
- The live TOP 10 panel and unobtrusive visit/play statistics occupy the upper right. POŘADÍ toggles the panel; its title opens the existing full leaderboard.
- Bottom HUD: POŘADÍ and ULOŽIT NA PLOCHU left; the existing personal-record label and JAK HRÁT right.
- Keep Passion CZ as the editable intro UI font. Palette: yellow `#ffe600`, ink `#121010`, pink `#f700ce`, white `#fffdf7`; artwork supplies orange and blue.

## Existing copy only

No new slogans or character dialogue are allowed.

- `INTRO_COPY.pepa` comes verbatim from the former intro bubble. Further rotating Pepa lines are his existing `QS` questions; their contents and the gate questions themselves remain unchanged.
- There is no dedicated woman-dialogue dataset in this repository. Her information bubble rotates the two existing sentences from `.in5-card`; it does not invent dialogue for her.
- Ticker sentences come verbatim from the three original help entries under “1 · Pepa u dveří”. The label is the existing section heading. No example slogans from the reference were added.
- Score, record and statistics use the existing data sources and formatting. No mock scores are shipped in the application.

## Motion and access

Ticker moves right to left at a constant rate, with two identical adjacent groups and a seamless loop. Hover/focus pauses it. Bubble changes use fade-in and a small scale transition, every nine seconds, and pause while a speech bubble is hovered or the scene contains keyboard focus, a modal is open or the document is hidden. Reduced-motion preference disables automatic movement and phrase rotation; the ticker can be scrolled manually.

Controls have visible keyboard focus. The mobile fallback uses a scrollable stacked composition and retains independent posters and controls.

## Preview and verification

```sh
npm ci
npm run dev
# In another terminal; Google Chrome must be installed:
npm run check:intro
npm run preview:intro
npm run build
```

`check:intro` mocks visit and leaderboard APIs locally, without changing shared data. Its test screenshots use sample scores and existing DJ names, saved as `shots/check-intro-*.png`. `npm run preview:intro` reads the original production TOP 10 and statistics through GET requests, then generates `shots/intro-*.png` with those exact names and scores. No records or scores are seeded in this preview; the personal record continues to depend on the device’s localStorage. All browser API writes are intercepted. It verifies both requested desktop sizes, protected face/car regions, equal poster frames, original copy/game data, ticker direction, menu controls, existing START/name/gate flow, mobile overflow, reduced motion, dynamic text, offline fallbacks and escaped leaderboard names.

## Approval boundary

This change is the visual preview phase only. Do not deploy it or proceed with new gameplay features before the user approves the screenshots. The existing START, help, installation instructions and leaderboard data flow remain wired to their existing implementations. No backend or game-rule changes belong in this redesign.
